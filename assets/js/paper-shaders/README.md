# Paper Shaders

Selected modules from `@paper-design/shaders` version **0.0.82**.
Source: https://github.com/paper-design/shaders
License: Apache-2.0; see LICENSE and NOTICE.

Includes ShaderMount, Dithering, Halftone Dots, and their required modules.
This repository keeps only the modules and exports used by its two effects.
Unused sizing/preset enums, GLSL helpers, mount convenience methods, and the
element predicate are removed. Source-map comments and trailing whitespace are
also removed. The active shader source, rendering, resizing, visibility handling,
and disposal behavior are preserved. Modified files carry subset notices.
The library is self-hosted. GitHub Pages needs no JavaScript build step.
